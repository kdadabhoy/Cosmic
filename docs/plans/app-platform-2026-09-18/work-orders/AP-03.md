# AP-03 — Editor UX: rect gizmo, Screens/DataBus panels, source links, live loop, template picker

**Gate:** G3 · **Wave:** 3 (alone) · **Runs:** worktree `ap/03` · **Base:** `main` after AP-02, AP-04 and
AP-D1 have landed · **Depends on:** all three · **Acceptance:** E01–E08, F01, V05 (editor half) ·
**Model:** Fable 5.1 · **Effort:** max · **Status:** not started

The editor side of the authoring workflow: arrange widgets with a rect gizmo, manage screens with a
linked C++ file each, see bus values while playing and set preview values while editing, open the
source behind anything with logic, edit C++ with the editor open and land back in Play on the same
screen, pick a real template, and prove it all with an editor self-test host the runner drives.
`StarforgeApp.cpp` is at the `/bigobj` limit: every new feature lives in a new TU, the shell only gets
hooks.
