# WO-03 — Enforce 2D across every supported entry point and CI

**Gate:** G2 · **Depends on:** WO-02 · **Acceptance:** B03–B05 · **Status:** not started

Make 2D-only the enforced shipping configuration everywhere a build can originate, so a stale cache
or a script default can never silently ship 3D (KI-3).

## Scope
- **In:** CMake option/preset defaults + trunk OFF-rejection; CI/release/package/scaffold/editor
  2D selection; mode-aware cache key; PR CI + GPU job; target-graph/manifest audit.
- **Out:** deleting 3D source; touching engine-3d; renderer/gameplay behaviour changes.

## Deliverables
Updated `CMakeLists.txt`/`CMakePresets.json`/`Cosmic`+`Starforge` CMake, `.github/workflows/*`,
`package*.bat`, project template; B03–B05 evidence.

## Done when (DoD)
B03–B05 pass from clean **and** stale-cache scenarios. A release/package job cannot produce a 3D or
mixed binary. Jolt + shared helpers remain. The CI cache key carries the mode.

## Rollback
Revert the CMake/CI/script commit; the candidate returns to the WO-02 baseline configuration.
