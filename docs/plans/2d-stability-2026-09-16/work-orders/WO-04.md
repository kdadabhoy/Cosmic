# WO-04 — Make acceptance executable, plus the injectable serial transport seam

**Gate:** G2 · **Depends on:** WO-02 (uses WO-05a's seam spec) · **Acceptance:** H01–H04 · **Status:** not started

The runner that turns the catalog into executable, observable evidence — **and** the injectable
transport seam without which the connected-state serial tests (WO-05) cannot run headlessly (KI-2).
The review pulled the seam out of WO-05 into here as a first-class deliverable.

## Scope
- **In:** the acceptance runner + evidence format + fixtures scaffolding; tier/profile separation;
  the injectable serial transport seam; H01–H04 self-tests.
- **Out:** authoring the individual T/D/R/C/N cases (their own WOs); real hardware qualification.

## Deliverables
`tests/acceptance/Run-Acceptance.ps1` + runner library + fixture metadata; the transport seam in
`Cosmic/src/serial/`; H01–H04 evidence.

## Done when (DoD)
H01–H04 prove the runner catches intentional failure, hang, missing suite/golden and missing GPU,
then a normal minimal case succeeds. The seam lets a fake transport drive the real connection state
machine. Nothing test-only ships in a package.

## Rollback
Runner + seam are additive; revert the commit to remove them. No behaviour change to production
serial paths (the seam is inert unless a test drives it — assert this).
