# UX & Shipping — acceptance catalog

Status: test specification, 2026-09-24. No case here has been executed. The execution model, tiers
(U unit / W in-process host / I editor self-test host / G GPU / Q qualification), profiles (`pr`, `release`,
`gpu`, `nightly`), evidence contract, isolation rules, deadlines and numeric bars are those of
[`../2d-stability-2026-09-16/03-Acceptance-Test-Catalog.md`](../2d-stability-2026-09-16/03-Acceptance-Test-Catalog.md)
and are not restated. Runner: `tests/acceptance/Run-Acceptance.ps1` with per-WO manifests
`ux<wo>-<group>.manifest.json`.

Retained unchanged from the earlier packets: every unit/render suite expectation (CosmicTests ≥ 523 / 0
failed / 14 skipped in both configs; CosmicRenderTests 45 with the 15 goldens byte-identical), B06, E06, E08,
K01–K04, Y01–Y03, S01–S04, DOC01–DOC03, DOC05 and every `ap*` / `wo*` manifest. A case that a lane extends
(E06, E08, K02) keeps its ID and its old oracle; the extension is listed under the new ID.
