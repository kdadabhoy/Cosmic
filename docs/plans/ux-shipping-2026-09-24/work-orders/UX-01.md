# UX-01: Flow editor and the Editors host (size, focus, link routing, trigger kinds, the ✕)

**Gate:** G1 · **Wave:** 1 (∥ UX-02, UX-03; lands first) · **Runs:** worktree `build\_lanes\ux-01`, branch
`ux/01` · **Base:** `main` after the packet commit (UX-00) · **Depends on:** UX-00 · **Acceptance:** FE01–FE05 ·
**Model:** Opus 5.5 · **Effort:** high · **Status:** not started

Kaden's items 5–8. A flow document opens in an undocked, unsized, unfocused "Editors" window with a fixed
330 px inspector, so the graph is tiny; backward transitions and self-loops are drawn straight through the
node boxes; the `when (guard only)` radio is one-way and can leave an empty guard that never fires; a new
flow is dirty before the user touches it; tabs are keyed by index; and the Editors ✕ does nothing while a
document is open. This lane fixes all of it in the editor and one minimal, documented patch to the vendored
node editor, and proves it headless plus through an editor self-test host.
