Cosmic Engine - third-party components in a packaged 2D app
===========================================================

This file ships in every Cosmic app package as licenses/THIRD-PARTY.txt. It names
every third-party component linked into the payload (<App>.exe, Cosmic.dll and
<App>.dll) of a COSMIC_2D_ONLY build, with its license. Where the upstream project
vendors a license file in this repository, that file is staged next to this one
(see the file name column); where it does not, the license is named here and the
canonical text is at the upstream URL.

Dev-only and 3D-only dependencies are NOT part of a 2D package and are therefore
not listed: doctest (unit tests), assimp and cgltf (3D mesh import),
recastnavigation (3D navmesh).

(the default). Its license is staged unconditionally so the package's file list
does not vary with that option.

The Cosmic Engine itself and the application content under assets/projects/<App>/
are not third-party material and are covered by their own terms.
